# This file is the single source of truth.  Every launch of the loader
# (press OK in the lobby) and of the overlay (Fetch offsets) downloads
# https://raw.githubusercontent.com/noverifylol/r6-offsets/refs/heads/main/offsets.txt
# and applies every key below.  Nothing is scanned in the game any more.
#
# Format:
#   key=0x1234      hexadecimal
#   key=123         decimal
#   key=1.25        float (only for the geometry/FOV keys)
#   # comment       whole line, or after a value
#
# Unknown keys and non-numeric lines are ignored, so a signature dump can
# be pasted in here without breaking anything.  An invalid or implausible
# value keeps the compiled default instead of zeroing the cheat.
#
# After a patch: change the numbers below, push, done.  Every customer
# has the new table on the next start.
#
# Reference for the numbers below: live dump of the current build
#   image_size=0x188BE000   (reference only - not read by the cheat)
# ============================================================
