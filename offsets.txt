# ============================================================
# v6Core offsets - paste this into
# https://github.com/noverifylol/r6-offsets/blob/main/offsets.txt
#
# This file is the single source of truth.  Nothing is scanned in the game.
#   * loader: press OK in the lobby -> table is downloaded -> overlay starts
#   * overlay: "Fetch offsets" button, and once on every start
#   * the entity list, the actor position, health and the camera all come
#     from the keys below.  A value that does not validate is reported in
#     v6core_debug.log instead of starting a scan.
#
# Download URL:
#   https://raw.githubusercontent.com/noverifylol/r6-offsets/refs/heads/main/offsets.txt
# Offline fallback, in this order: offsets.cache -> offsets.txt next to the
# executable -> built-in defaults.
#
# Format:
#   key=0x1234      hexadecimal
#   key=123         decimal
#   key=1.25        float (geometry/FOV keys only)
#   # comment       whole line, or after a value
#
# Unknown keys and non-numeric lines are ignored, so a signature dump can be
# pasted in here without breaking anything.  An invalid or implausible value
# keeps the built-in default instead of zeroing the cheat.
#
# After a patch: change the numbers below, push, done.  Every customer has
# the new table on the next start.
#
# Reference: live dump of the current build (October 2026)
#   image_size=0x186C5000   (reference only - not read by the cheat)
#   actor-list signature: 48 8B 0D ?? ?? ?? ?? BA 01 00 00 00 E8 ... 83 FA 02
# ============================================================
